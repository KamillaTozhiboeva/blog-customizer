# Blog Customizer

Интерактивное веб-приложение для динамической настройки внешнего вида статьи. Проект демонстрирует работу с локальным состоянием, компонентный подход и передачу данных между независимыми блоками интерфейса.

## Функциональность

- **Динамическая стилизация:** Настройки интерфейса транслируются в приложение через CSS-переменные.
- **Управление состоянием:** Изменения в панели настроек сохраняются локально и применяются к статье только после явного подтверждения (кнопка «Применить»).
- **Интерактивный сайдбар:** Панель настроек открывается по клику на стрелку и закрывается при повторном нажатии или клике вне области сайдбара.
- **Сброс параметров:** Возможность отката всех настроек к дефолтным значениям в один клик.
- **Изолированная разработка UI:** Проект интегрирован со Storybook для тестирования и просмотра компонентов в изоляции.

## Скрипты для запуска

В проекте настроены инструменты для контроля качества кода и стилей:

- `npm run storybook` — запуск песочницы компонентов Storybook.
- `npm run lint` — запуск линтера для проверки JavaScript/TypeScript кода.
- `npm run stylelint` — запуск линтера для проверки CSS/SCSS стилей.
- `npm run format` — автоматическое форматирование кода.
